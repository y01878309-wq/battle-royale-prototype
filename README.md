# 🚆 مشروع لعبة قطارات مصر - Egypt Trains Simulator

أهلاً بك يا يوسف! هذا الملف يحتوي على جميع ملفات التحديث المتكاملة للعبة **"قطارات مصر"**.

## 📁 محتويات الملف:
1. `index.html`: ملف الواجهة الرئيسية والكابينة والمتجر والـ 30 شغلانة.
2. `style.css`: التصميم المخصص للموبايل والتابلت بوضع العرض (Landscape) والألوان الواقعية.
3. `game.js`: البرمجة الكاملة لـ 30 شغلانة، فتح الأبواب، الكلاكس، السرعة، ورصيد فودافون كاش.

## 🚀 طريقة التحديث على GitHub و Vercel:
1. فك الضغط عن ملف ZIP.
2. افتح المستودع الخاص بك على GitHub أو في تطبيق Acode على الموبايل.
3. استبدل ملفات `index.html` و `style.css` و `game.js` بهذه الملفات الجديدة.
4. قم بعمل Commit & Push للـ GitHub وسيقوم Vercel بتحديث اللعبة تلقائياً بالشكل الجديد المذهل!
