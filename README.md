# قطارات مصر

لعبة قيادة قطار مصري ثلاثية الأبعاد (Three.js). الحسابات والمحفظة والمسابقات واللعب الأونلاين على Firebase.

## الملفات
- `index.html` + `js/` + `css/` : اللعبة (ترفعها على Vercel).
- `admin.html` : لوحة الأدمن (شحن بالـ ID، أكواد هدية، صرف جوايز، نشر الكتالوج). مفتوحة بدخول جوجل بإيميلك بس.
- `catalog.json` : أسعار القطارات ومكافآت المهام (بتنشرها من admin.html). بيتولّد بـ `node tools/make-catalog.js`.
- `firebase/firestore.rules` و `firebase/database.rules.json` : قواعد الأمان (تتلصق في Firebase Console).

## الإعداد (مرة واحدة)
1. Authentication: فعّل Anonymous (من غير التنظيف التلقائي) و Google، وضيف دومين Vercel في Authorized domains.
2. Firestore Database: Rules ← الصق `firestore.rules` بعد ما تغيّر الإيميل جواه ← Publish.
3. Realtime Database: Rules ← الصق `database.rules.json` ← Publish.
4. افتح `admin.html` من موقعك، ادخل بجوجل، دوس «انشر الكتالوج».

## الشحن
اللاعب يبعتلك فودافون كاش ويكتبلك الـ ID (6 أرقام من الإعدادات ← حسابي). من admin.html اكتب الـ ID والمبلغ واضغط «اشحن».

## حدود الأمان
من غير سيرفر خاص، القواعد بتمنع الغش العادي (زيادة الرصيد، شراء من غير فلوس، استلام مكافآت مرتين) وبتحدد الأرباح بحد أقصى لكل رحلة ولكل يوم. لكن مش بتمنع لاعب مصمم من الوصول لحد الأرباح اليومي بدون ما يلعب. لا تعتمد على الرصيد كقيمة مالية عالية.

## تحديث (نوفمبر ٢٠٢٦)
- الأدمن: دخول بالإيميل وكلمة السر (من Authentication ← Users) أو جوجل بنافذة. الصفحة بتعرض الـ UID، حطه في `firebase/firestore.rules` مكان `PUT-ADMIN-UID-HERE` والصق القواعد في Firestore ← Rules ثم Publish. بعدها افتح admin.html واضغط «انشر الكتالوج».
- عملة «الماسة» 💎 للشحن فقط + 5 قطارات بيها، ورسالة «رصيدك خلص» برقم الشحن.
- ٣ و٤ سكك من الإعدادات ← طريقة اللعب (الافتراضي ٣).
- صفحة الحقوق والشروط ملك يوسف فرج ويوسف خربوش.
