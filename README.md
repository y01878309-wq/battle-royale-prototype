# قطر الصعيد

محاكي قطار مصري ثلاثي الأبعاد على خط الجيزة – الواسطى – بني سويف – المنيا، بجانب النيل. كل الخامات والأصوات متولّدة بالكود، فمفيش صور أو ملفات صوت.

## التشغيل

```
npm install        # بينزّل three@0.128.0 وينسخه في vendor/
npm start          # سيرفر محلي، افتح العنوان اللي يظهر
```

من غير npm: افتح `index.html` من أي سيرفر ثابت (مش `file://`). الصفحة بتحمّل Three.js من cdnjs، ولو فشل بتحمّله من `vendor/three.min.js`.

## التحكم

| زر | وظيفته |
|---|---|
| W / S | زيادة / تقليل القوة (8 درجات) |
| مسافة | فرامل (بتزيد تدريجيًا) |
| E | فرملة طوارئ |
| H | الزمارة |
| C | تغيير الكاميرا |
| P | إيقاف مؤقت |
| M | كتم الصوت |

على الموبايل: شريط القوة وأزرار الفرامل والزمارة على الشاشة.

## اللعب

- وقّف عند علامة «قف» في كل محطة. الدقة بتحدد النقاط، والوصول في الميعاد بيدي مكافأة.
- الأبواب بتفتح والركاب بيركبوا، وبعدين الإشارة تبقى خضرا.
- التزم بلافتات السرعة (90 / 60 قرب المحطات، 80 عند المزلقانات، 120 على الخط).
- المزلقانات بتقفل لوحدها لما القطر يقرّب.
- الوقت: صبح، ضهر، غيم، غروب، ليل (بالليل الأنوار والشبابيك بتنوّر).
- القاطرة والعربيات بألوان السكة الحديد المصرية (أحمر ورمادي فضي).

## تحويله لتطبيق

- **موبايل:** Capacitor (`npm i @capacitor/core @capacitor/cli`، `npx cap init`، اجعل `webDir` هو `.`، ثم `npx cap add android`).
- **كمبيوتر:** Electron أو Tauri بنفس الطريقة، والمدخل `index.html`.

## هيكل الملفات

- `track.js` السكة (سبلاين مغلق، قضبان، فلنكات)
- `world.js` الأرض والنيل والجبل والأهرامات والفلايك
- `scenery.js` النخل والقرى والمآذن والتلغراف والمزلقانات
- `train.js` القاطرة والعربيات والكابينة
- `stations.js` المحطات والإشارات ولافتات السرعة
- `game.js` الفيزيا والنقاط (بدون رسم، قابل للاختبار)
- `audio.js` الصوت، `ui.js` الواجهة، `main.js` الربط وحلقة اللعب
